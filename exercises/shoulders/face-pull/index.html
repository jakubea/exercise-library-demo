Face Pull

The Face Pull is a beginner isolation exercise for the shoulders, with help from the back. It uses cable.

How to do it

  1. Set a rope at face height and step back with arms extended
  2. Pull the rope toward the face with the elbows high
  3. Pause then return slowly

Common mistakes

  • Pulling with too much weight and leaning back
  • Dropping the elbows below the hands
