Cable Crunch

The Cable Crunch is a intermediate isolation exercise for the core. It uses cable.

How to do it

  1. Kneel facing a high pulley holding the rope at the head
  2. Curl the ribs toward the hips
  3. Return slowly without sitting back

Common mistakes

  • Pulling with the arms instead of the abs
  • Hinging from the hips
