Incline Dumbbell Curl

The Incline Dumbbell Curl is a intermediate isolation exercise for the biceps, with help from the forearms. It uses dumbbell.

How to do it

  1. Sit back on an incline bench and let the arms hang straight down
  2. Curl both dumbbells up keeping the upper arms still
  3. Lower to a full stretch

Common mistakes

  • Moving the elbows forward
  • Using weights that are too heavy to control
